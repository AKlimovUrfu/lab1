# Лабораторная №1: основы Python и NumPy

Цель — закрепить базовый Python, работу с массивами NumPy, индексирование,
векторизацию и обработку граничных случаев.

## Как выполнять

1. Установите Python 3.11+ и `numpy`.
2. Реализуйте функции в `python_basics.py` и `numpy_tasks.py`.
3. Не меняйте директорию `grader_contracts`: это публичный контракт проверки.
4. Можно добавлять свои модули и тесты. Обязательные функции должны оставаться
   верхнеуровневыми и принимать указанный contract object.
5. Зафиксируйте решение в Git и отправьте точный commit SHA.

В заготовках параметры уже распакованы в локальные переменные. Реализуйте тело
после `TODO`, сохранив тип результата. Проверка использует дополнительные и
граничные случаи; лимиты — **1 CPU и 256 МБ RAM**.

## Часть 1. Python

1. `count_vowels`: количество латинских гласных `a, e, i, o, u` без учёта регистра.
2. `has_unique_characters`: встречается ли каждый символ строки не более одного раза.
3. `count_one_bits`: количество единичных битов положительного целого числа.
4. `multiplicative_persistence`: число перемножений цифр до получения одной цифры.
5. `mse`: средняя квадратичная ошибка двух целочисленных векторов одинаковой длины.
6. `prime_factorization`: строка `(n1**p1)...`; степень `1` не печатается.
7. `pyramid`: представить `n` как `1²+2²+...+k²`; вернуть `k` либо `It is impossible`.
8. `is_balanced_number`: сравнить суммы цифр слева и справа от средней цифры
   или двух средних цифр, которые не входят в суммы.

## Часть 2. NumPy

1. `sum_prod`: сумма произведений `p` матриц `(n,n)` на соответствующие векторы `(n,1)`.
2. `binarize`: значения строго больше threshold становятся `1`, остальные — `0`.
3. `unique_rows`, `unique_columns`: уникальные значения каждой строки/колонки.
4. `matrix_statistics`: normal-матрица по `seed`, средние и дисперсии строк/колонок.
5. `chess`: матрица `(m,n)` в шахматном порядке из `first` и `second`.
6. `draw_rectangle`, `draw_ellipse`: RGB-изображение с центрированной фигурой.
7. `analyze_time_series`: mean, variance, std, строгие локальные экстремумы и moving average.
8. `one_hot`: one-hot encoding неотрицательных меток с опциональной шириной `class_count`.
